## Dataset

Am ales un dataset cu filmele si serialele de pe Netflix, de pe Kaggle: [Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows).

Contine aproximativ 8.800 de titluri, atat filme cat si seriale, cu informatii precum titlul, regizorul, actorii, anul lansarii, tara, genul si o scurta descriere.

## Proprietati

| Proprietate | Tip | Descriere |
| --- | --- | --- |
| `type` | `string` | Film sau serial |
| `title` | `string` | Titlul |
| `director` | `string` | Regizorul |
| `release_year` | `int` | Anul lansarii |
| `cast` | `string` | Actorii |
